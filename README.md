# PC-Spec-Comparer
A rough PC specification comparison tool.

This small project will be used to help compare the specifications of x86 based Personal Computers,
starting off with storing and comparing individual components. For now, all components entered require manual input.

---
## Roadmap:


| Stage           | Name                                          | Goal                                                                                                                                  | Timeline |
|-----------------|-----------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------|----------|
| Initialization  | Basic functionality of CPU calculation        | Storing CPU specifications from user input, Calculating a rough performance score, Outputting the score back to the user via terminal | None yet |
| Stage 1         | Solidifying formula for CPU calculation       | Fine tune CPU spec calculator to be more consistent with a wide range of CPUs                                                         | None yet |
| Stage 2         | Initialization of GPU calculation             | Add the ability to compare GPUs with each other and output scores just like CPUs, calculate a combined score of CPU and GPU scores    | None yet |
| Stage 3         | Solidifying formula for GPU + CPU calculation | Add functionality to display potential bottlenecks between the two components                                                         | None yet |      
More features will be added over time, this roadmap only highlights my current plans for the program at this moment.
